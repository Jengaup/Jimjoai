Accessibility statement

A site everyone can use.

I want anyone to be able to browse this site and reach me, however they access the web.

Last reviewed: November 8, 2026

Goal

This site aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2, level AA. It’s ongoing work: there may be areas I’m still improving.

What’s been done

  • Ordered headings, page regions (navigation, content, footer) and a link to skip to the content.
  • Everything works with a keyboard, with a visible focus indicator. The mobile menu closes with Escape.
  • Forms with labels, error messages tied to each field and status updates that screen readers announce.
  • Color contrast checked, and animations that stop if you turn on reduced motion in your system.
  • A layout that adapts to phones, tablets and browser zoom up to 200%.

How it’s been checked

With automated tests (axe-core), keyboard walkthroughs, reduced-motion simulation and visual review at different screen sizes. It has not yet been evaluated with people who use assistive technologies.

Known limitations

  • The animated dashboard on the home page is an illustration. Screen readers get a description instead of its contents.
  • Calendly scheduling is an outside service, so its accessibility depends on that provider. If it’s hard to use, please use the contact form.

Report a barrier

If something doesn’t work for you, write to me through the contact form. It helps a lot if you include:

  • The page where it happened
  • What you were trying to do and what happened
  • Your browser and device
  • The assistive technology you use, if any (for example, a screen reader)

If the form itself is the barrier, you can book a call from any “Book a call” button.
